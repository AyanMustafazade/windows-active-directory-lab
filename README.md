# Windows Server & Active Directory Lab

Hands-on Windows Server and Active Directory administration project demonstrating the deployment and management of a Windows domain environment.

## Technologies & Tools

- Windows Server
- Windows 10 Client
- Active Directory Domain Services (AD DS)
- Active Directory Users and Computers (ADUC)
- DNS
- DHCP
- Group Policy (GPO)
- NTFS & Share Permissions
- IIS Web Server
- CMD & PowerShell

## Skills Demonstrated

- Windows Server network and hostname configuration
- Active Directory Domain Services deployment
- Domain Controller configuration
- Windows client domain joining
- Organizational Unit (OU) management
- Domain user and Security Group management
- DNS record configuration
- DHCP configuration
- Group Policy creation and deployment
- CMD, PowerShell and Task Manager restrictions
- USB/removable storage restrictions
- Shared folder configuration
- NTFS and Share permissions
- IIS Web Server deployment

## Enterprise Active Directory Project

The lab simulates the administration of a Windows enterprise environment using Active Directory.

### Active Directory

- Installed Active Directory Domain Services
- Promoted Windows Server to a Domain Controller
- Created the `aztu.local` domain
- Joined a Windows client to the domain
- Created organizational units for different departments
- Created and managed domain users and security groups

### DNS & DHCP

- Configured DNS records
- Configured DHCP services
- Tested network connectivity and name resolution

### Group Policy

Implemented Group Policies to manage and restrict domain users, including:

- CMD restrictions
- PowerShell restrictions
- Task Manager restrictions
- USB/removable storage restrictions

### File Server & Permissions

- Created shared folders
- Configured NTFS permissions
- Configured Share permissions
- Applied group-based access control

### IIS Web Server

Installed and configured IIS to deploy and test a web service in the Windows Server environment.
